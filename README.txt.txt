TEMPERATURE TREND VISUALIZATION DASHBOARD

Project Description:
This project is a Python-based Temperature Trend Visualization Dashboard.
It analyzes temperature data and displays useful information through charts
and a simple dashboard.

Technologies Used:
- Python
- NumPy
- Pandas
- Matplotlib
- Tkinter
- CSV

Features:
- Average Temperature
- Maximum Temperature
- Minimum Temperature
- Total Records
- Hot, Normal and Cold Temperature Categories
- Line Chart
- Bar Chart
- Pie Chart

How to Run:
1. Open Command Prompt in the project folder.
2. Run: py main.py

Data File:
temperature_data.csv
